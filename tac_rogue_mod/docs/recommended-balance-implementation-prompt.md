# Recommended Balance Implementation Prompt

## Summary
- `floor5-plus-balance-simulation-report.md` の `Recommended Direction` を実装する。
- 5層ボスの初回体験を軽くする。
- 30層以降の敵圧を、HP盛りだけではなく特殊個体/アーマー/速度/遠距離圧で戻す。
- 終盤の火力パーク乗算が暴れすぎないよう、銃ダメージ計算にソフトキャップを入れる。

## Boss Changes
- 独自ボス基礎HPを `120 -> 100`。
- 独自ボス基礎移動速度を `0.22 -> 0.25`。
- ボスHP倍率:
  - `5.0 + 0.30f + 0.005f^2`
  - から
  - `3.6 + 0.22f + 0.0045f^2`
- 5層ボス想定:
  - 約 `455 HP`
  - 防御 `8-9` 程度。
- ボス防御:
  - `10 + floor * 0.5`
  - から
  - `min(7.0 + floor * 0.30, 30.0)`
- ボス移動:
  - ターゲットがいるとき、一定間隔でナビゲーションを再要求する。
  - 速度下限を `0.16` にする。
  - 重力/物理を通常状態へ戻す。

## Floor 30+ Enemy Pressure
- `RogueMobVariant` に高階層補正を追加する。
- 30層以降:
  - 特殊個体に軽いアーマー追加。
  - 移動速度を少し上げる。
  - 攻撃力を少し上げる。
- 50層以降:
  - 高階層用の特殊個体を追加する。
  - 遠距離/装甲/妨害寄りで、通常敵を単純に硬くするだけにしない。
- 通常敵全体のHP式は今回は大きく変更しない。

## Perk Firepower Softcap
- 銃ダメージ計算時の `DAMAGE` と `GUN_PROFICIENCY` にソフトキャップを入れる。
- 低〜中層の効果はほぼ維持する。
- 150-160%を超えた分だけ伸びを圧縮する。
- `FORTUNE`, `HEAD_HUNTER`, `RELOAD_SPEED` は今回大きく変えない。
  - 既にクリティカル率/ヘッドショット/リロード下限があるため。

## Test Plan
- `.\gradlew.bat build` が成功すること。
- 5層ボスの最大HPが約450-520帯になること。
- ボスがターゲットへ移動し続けること。
- 30層以降の特殊個体が少し硬く/速く/危険になること。
- 銃ダメージが低層ではほぼ変わらず、高層大量パーク時だけ伸びが圧縮されること。
