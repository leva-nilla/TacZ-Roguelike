# Boss Mobility / Floor 5 Balance Prompt

## Summary
- 独自ボスが移動しない、または移動しているように見えない問題を修正する。
- 5層ボスの耐久が初回ボスとして硬すぎる可能性があるため、100層以上の長期スケールを残しながら序盤ボスだけ軽くする。

## Current Findings
- `TacRogueBossEntity` は `MeleeAttackGoal` と通常ナビゲーションを持つが、移動速度が `0.22 * BOSS_SPEED_MULT(0.5) = 0.11` まで落ちる。
- ボスは近接AI中心なので、プレイヤーとの距離や段差、経路計算の失敗で止まって見えやすい。
- 5層ボスHPは基礎 `120` に倍率 `6.28` がかかり、約 `754 HP` になる。
- 5層ボス防御は `10 + 5 * 0.5 = 12.5` で、初回ボスとして実効耐久がさらに重い。

## Mobility Fix
- ボスの基本移動速度を少し上げる。
  - `0.22` -> `0.25`
- ボススケーリング後の速度下限を保証する。
  - 低階層でも最低 `0.16`
  - 上限は従来通り過剰に速くしない。
- `tick()` 内でターゲットがいる場合、距離があるときにナビゲーションへ追跡を再要求する。
  - 近接AIを置き換えず、経路再取得の補助として使う。
  - 毎tick大量処理にならないよう、軽い間隔で実行する。
- 詰まり対策として、ボスの重力/物理は明示的に通常状態にする。

## Floor 5 Boss Balance
- 5層時点のHPを約 `450-520` 程度まで落とす。
- 100層以上では十分硬くなるよう、二次スケールは維持する。
- 推奨式:
  - 基礎HP: `120 -> 100`
  - HP倍率: `5.0 + 0.30f + 0.005f²` -> `3.6 + 0.22f + 0.0045f²`
- 5層防御は `12.5` から `8-9` 程度へ落とす。
  - 推奨式: `min(8.0 + floor * 0.30, 30.0)`
- 攻撃力は今回大きく下げない。
  - すでに序盤通常敵ダメージを下げているため、ボスは危険な存在として残す。

## Test Plan
- `.\gradlew.bat build` が成功すること。
- 5層ボスがターゲットに向けて歩いてくること。
- 壁や柱で一時停止しても、再度ターゲットへ向かうこと。
- 5層ボスが初回ボスとして長すぎない耐久になること。
- 50層/100層想定のHP倍率が過度に低くならないこと。

## Assumptions
- 100層以上プレイ前提なので、高階層の成長は残す。
- 今回はボスの能力構成や報酬は変えない。
- まずは体感の硬さと移動不全を直す。専用の遠距離攻撃AI追加は次段階に回す。
