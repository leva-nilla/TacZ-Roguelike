# Armor, Stamina, Reload Perk, Third-Person Aim Fix Prompt

## Summary
- アーマーがバニラ属性上限の 30 で止まる問題を解消し、ローグライク側のパーク/一時効果が上限で無効化されないようにする。
- 日本語表示時に Tactical State / 詳細効果へ残っている英語文言を翻訳キー化する。
- 三人称で壁に近いとき、クロスヘア表示点と実際の着弾基準がずれる問題を修正する。
- レアリティに加えて RELOAD_SPEED パークも実リロード時間と TacZ リロードアニメーション短縮に反映する。
- AMMO_EFFICIENCY の実効弾薬節約率に上限を設け、100% 到達を防ぐ。
- スタミナ最大値増加後もバニラ満腹度のしきい値に阻まれず、スタミナが残っていればダッシュ開始できるようにする。

## Key Changes
- TacZ 本体 jar は直接改変しない。既存の Mixin とイベント処理で補正する。
- アーマー:
  - `Attributes.ARMOR` の値が 30 で sanitize される箇所を互換性のある Mixin で補正し、ローグライク用の上限まで許可する。
  - 表示値とパーク反映値が一致するよう、既存のパーク tick 処理は維持する。
- 日本語表示:
  - Status 詳細行の固定英語文字列を `Component.translatable` 経由にする。
  - `ja_jp.json` / `en_us.json` に Tactical State と詳細効果用キーを追加する。
- 三人称クロスヘア:
  - まず LeaWinds CAMERA_AGENT またはカメラレイで狙点を決める。
  - その狙点に対してプレイヤー eye から再レイキャストし、実際の射撃方向で当たる点を最終クロスヘア位置にする。
  - 壁際ではカメラの見た目上の hit ではなく、射撃基準の hit を表示する。
- リロード:
  - `WeaponRarity.getReloadMult` はレアリティ単体の値として残す。
  - 新しく「レアリティ倍率 x RELOAD_SPEED パーク倍率」の実効リロード倍率を取得する helper を追加する。
  - サーバー側リロード短縮 Mixin とクライアント側 `ObjectAnimationRunner` Mixin の両方で同じ実効倍率を使う。
  - COMMON やパークなしでは従来速度のままにする。
- Ammo Save:
  - 乗算スタック後の実効節約率を最大値で clamp する。
  - 発動判定とステータス表示の値を同じ上限に合わせる。
- スタミナ:
  - ローグライク側の実スタミナが 0 より大きい間は、バニラの「満腹度 6 以下ではダッシュできない」判定に引っかからない最低表示値を維持する。
  - 満腹度を 18 以上にはしないことで、バニラ自然回復の暴発は引き続き避ける。

## Test Plan
- `.\gradlew.bat build` が成功すること。
- ビルドした jar を Modrinth プロファイルへ配置すること。
- アーマー:
  - アーマーパーク/アーマープレート適用時に 30 で止まらず、Status 表示も増えること。
- 日本語表示:
  - Tactical State と詳細効果の dodge / damage taken / ammo save / regen / reload 系が日本語で読めること。
- 三人称:
  - 壁際、前後移動、左右移動でクロスヘア表示点と着弾基準が大きくずれないこと。
  - 一人称の挙動は変わらないこと。
- リロード:
  - レアリティなし/パークなしは従来速度のまま。
  - RELOAD_SPEED パーク取得時、弾の装填完了とリロードアニメーションが同じ方向に短縮されること。
- Ammo Save:
  - パークを重ねても 100% 節約にはならず、Status 表示も上限値で止まること。
- スタミナ:
  - スタミナ最大値増加後、スタミナが少しでも残っていればダッシュ開始できること。

## Assumptions
- 弾薬節約率の上限はゲーム性維持のため 85% とする。
- 実効リロード倍率の下限は極端なアニメーション破綻を避けるため 0.35 とする。
- アーマー属性のローグライク上限は 100 とする。
