# スタッシュGUI・全チェストインベントリ・三人称反動改善仕様

## Summary
- スタッシュGUIを、単なるバニラチェスト風グリッドではなく、保管アイテムを探しやすい一覧型UIに寄せる。
- チェストを開いたときのプレイヤー側インベントリを、ステータス画面のRogue専用インベントリと同じスロット構成に統一する。
- 三人称視点の反動を一人称視点と近い体感にし、射撃方向・クロスヘア同期と競合しないようにする。

## Key Changes
- スタッシュGUI:
  - スタッシュ側の中身は既存の `ChestMenu` / `PlayerStash` を維持し、保存形式は変えない。
  - 表示を「アイテム一覧」寄りに変更し、アイコン・名前・個数・レアリティ/カテゴリが読み取りやすい構成にする。
  - スロット操作は既存のチェスト操作を維持する。
  - 将来的な検索・カテゴリフィルタ追加を見越して、描画とスロット配置を分離する。

- チェストGUI:
  - Rogueダンジョン内の専用チェストだけでなく、通常チェストを含むすべてのチェスト系コンテナに対応する。
  - バニラチェスト、トラップチェスト、ラージチェストを対象にする。
  - 可能なら他Mod追加チェストも、ForgeのMenu/Container判定で安全に拾える範囲まで対応する。
  - ただし、独自処理が強い特殊コンテナやクラッシュリスクがあるものは除外できるようにする。
  - 開いたときのプレイヤー側インベントリ表示は、ステータス画面の専用インベントリと同じレイアウトに統一する。
  - 銃スロット、近接スロット、拡張ホットバー、通常アイテム欄を同じ見た目・同じ操作感で扱えるようにする。
  - チェスト側の中身は従来通り維持し、アイテム移動ルールだけRogue側の専用スロット仕様に合わせる。

- 三人称反動:
  - TacZ本体jarは直接改変しない。
  - LeaWinds連携側の反動補正を見直し、一人称と三人称で反動量が過剰に変わらないようにする。
  - クロスヘア/射撃方向同期と反動注入の基準を分けず、三人称時も表示と射撃のズレを増やさない。
  - 反動を強く見せるための固定倍率が不自然な場合は撤去または弱める。

## Test Plan
- `.\gradlew.bat build` が成功すること。
- スタッシュ:
  - 保管中アイテムが一覧として見やすく、クリック/Shiftクリック操作が壊れていないこと。
  - 銃・弾薬・アタッチメント・通常アイテムの表示が破綻しないこと。
- チェスト:
  - 通常チェスト、トラップチェスト、ラージチェストを開いたときにRogue専用インベントリ構成で表示されること。
  - ダンジョン補給チェストも同じ操作感で開けること。
  - 特殊コンテナは安全に対象外へ逃がせること。
- 三人称:
  - 一人称と三人称で同じ武器を撃ち、反動の体感差が大きくないこと。
  - 左右移動中、ADS中、腰撃ち中にクロスヘアと射撃方向が大きくズレないこと。
  - LeaWinds有効時にクロスヘア重複表示が再発しないこと。

## Assumptions
- チェストGUIはRogue専用チェストに限定せず、通常チェストを含むすべてのチェスト系コンテナに適用する。
- 他Modの特殊チェストは安全に判定できるものだけ対応し、危険なものはバニラ/元Mod画面へフォールバックする。
- チェストの中身や保存形式は変えず、表示とプレイヤー側インベントリ操作だけをRogue仕様へ寄せる。
- 三人称反動は完全なTacZ内部改変ではなく、既存のLeaWinds互換レイヤーで体感差を縮める。
