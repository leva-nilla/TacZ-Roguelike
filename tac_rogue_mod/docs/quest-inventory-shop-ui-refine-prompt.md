# Quest / Inventory / Shop UI Refinement Prompt

## Goal

既存のゲーム内容は変えず、見づらいGUIとアクセスしづらい追加スロットを整理する。クエスト画面、専用ホットバー、ローグ用インベントリ、ショップカテゴリ幅、Volatile説明を調整して、プレイヤーが現在の状態と報酬を直感的に把握できるようにする。

## Scope

### 1. Quest GUI

- `QuestScreen` をスクロール前提の一覧画面に再構成する。
- クエスト一覧は中央のリストとして表示し、マウスホイールで上下スクロールできるようにする。
- 選択中のクエスト詳細は右側に表示する。
- 報酬表示は右側パネル内で独立した「REWARD」領域として見やすくする。
- 報酬領域には以下を表示する。
  - ゴールド報酬
  - レア武器報酬の有無
  - 完了済み/進行中の状態
- 長い文言は `font.split` で折り返し、狭い画面でも文字がはみ出さないようにする。

### 2. Hotbar HUD

- 既存の16枠構成は維持する。
  - Gun 1
  - Gun 2
  - Melee
  - Item 3-11
  - Ammo 12-15
- ただし、表示をより専用UIらしく整理する。
- 追加された item 9-11 が通常ホットバーとは別枠であることがわかるよう、区切りと小ラベルを明確にする。
- 画面下部で横幅が広くなりすぎないよう、スロットサイズと余白を調整する。

### 3. Rogue Inventory GUI

- バニラインベントリ風の配置から、ローグ用の専用レイアウトへ寄せる。
- 実際に使われるプレイヤーインベントリスロットを、画面上でも同じ意味の場所に並べる。
  - Gun: player inventory slot 0-1
  - Melee: slot 2
  - Items: slot 3-11
  - Ammo: slot 12-15
  - Backpack / expandable: slot 16-35
- 特に item slot 9-11 を専用アイテム列に配置し、クリック可能なスロットとして明示する。
- 鎧、クラフト、オフハンドなどローグ用途から外れているバニラ要素は暗くするか、邪魔にならない位置へ退避する。
- 既存のインベントリ制御、スタッシュ送り、ロック表示の挙動は変えない。

### 4. Shop Category Width

- `ShopScreen` のカテゴリタブ幅を小さくする。
- 目安:
  - 現在 132px 程度
  - 変更後 84-96px 程度
- グリッド領域を左に寄せ、商品一覧と詳細の表示領域を少し広げる。
- カテゴリの1列スクロールと互換性ハイライトは維持する。

### 5. Volatile Modifier Description

- 現行コードでは `VOLATILE` はフロアクリア時自傷ではなく、被ダメージ増加として処理されている。
- `ja_jp.json` / `en_us.json` の説明を実装に合わせて修正する。
  - Japanese: 「不安定型。効果倍率 2.00倍。被ダメージが増加。」
  - English: "Volatile. 2.00x effect power. Increases damage taken."
- フロアクリア時ダメージの新規実装は行わない。

## Non Goals

- クエスト内容、報酬量、進行条件のバランス変更はしない。
- インベントリ容量そのものの拡張仕様は変えない。
- 新しいキー割り当てやネットワークプロトコル変更は、必要にならない限り追加しない。
- 既存のショップ商品データ、価格、互換性判定は変えない。

## Validation

- `.\gradlew.bat build` が成功すること。
- `QuestScreen` がクエスト数の多い状態でもスクロールできること。
- `RogueInventoryScreen` 上で slot 9-11 が見えてクリック対象として扱えること。
- `ShopScreen` のカテゴリ幅が縮まり、商品グリッドと詳細表示が破綻しないこと。
- `Volatile` の説明が実装内容と矛盾しないこと。
