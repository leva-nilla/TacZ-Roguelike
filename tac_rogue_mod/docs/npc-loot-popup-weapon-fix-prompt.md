# NPC Menu / Loot / Popup / Weapon Fix Prompt

## 日本語概要
この改修では、NPCインタラクト時の体験、探索報酬、通知表示、クエスト報酬武器、レアリティ武器性能、パーク選択画面の読みやすさをまとめて整理する。

現状はNPCに話しかけるとポップアップが出る一方で、ショップやクエスト画面も即座に開いてしまう。これにより「会話して選ぶ」感覚がなく、ゲームらしさが弱い。  
また、ダンジョン内のチェストが空で多く生成されるため、探索報酬として機能していない。通知ポップアップも複数同時に出ると画面を占有しやすい。  
武器面では、クエスト報酬のレア武器が完全ランダムではなく、章に基づく候補選択になっている。さらに序盤から強い武器が出る可能性があるため、章/階層に応じた制限が必要。  
レアリティ武器のリロード短縮とマガジンサイズ補正は、NBT上の表示だけでなく、実際にTacZ側の挙動へ反映できているか確認し、可能なら実装する。

## 現状確認メモ
- クエスト報酬のレア武器は、現状「完全ランダム」ではない。
  - `selectRareWeaponReward(int chapter)` が候補を価格順に並べ、`chapter * 37` の固定的なインデックスで選んでいる。
  - つまり章ごとにほぼ決まる疑似選択で、プレイごとのランダム報酬ではない。
- 序盤でも高価格候補が選ばれる可能性がある。
  - 現在は候補を価格の高い順に並べているため、序盤報酬として強すぎる武器が出やすい。
- レアリティはNBTに以下を持つ。
  - `RogueDamageMult`
  - `RogueReloadMult`
  - `RogueMagMult`
  - `RogueRarity`
- ダメージ補正は既存戦闘処理で確認済みの可能性が高いが、リロード短縮とマガジン補正はTacZ API/ミックスイン/イベントで実際反映されているか再確認が必要。

## 1. NPCインタラクトメニュー化
- NPCにインタラクトした時、即ショップ/クエスト/階層選択を開かない。
- 代わりにNPC会話メニュー画面を開く。
- NPCごとに選択肢を出す。
  - Commander
    - クエストを見る
    - 作戦説明を聞く
    - 閉じる
  - Quartermaster
    - ショップを開く
    - 補給の説明を聞く
    - 閉じる
  - Intelligence Officer
    - 階層情報を見る
    - 階層選択を開く
    - 閉じる
  - Medic
    - 回復する
    - 医療説明を聞く
    - 閉じる
- ダンジョン内の回収要員は例外。
  - フロアクリア済みなら「帰還/次画面へ進む」選択を出す。
- 会話文はチャットではなく画面内テキスト、または軽量ポップアップにする。
- メニューから選んだ時だけ、ショップやクエストタブを開く。

## 2. Shop / Quest タブの制限
- `RogueInventoryScreen` の上部タブから `SHOP` と `QUEST` を直接開けないようにする。
- ShopはQuartermaster経由でのみ開く。
- QuestはCommander経由でのみ開く。
- 既存の内部処理としてはタブ自体は残す。
  - NPCメニューから開く時に `RogueInventoryScreen.Tab.SHOP` / `QUEST` を指定する。
  - デバッグ用途や将来拡張のため、描画処理自体は削除しない。

## 3. ダンジョン内チェストの探索報酬化
- チェスト生成数をフロアあたり1〜2個程度に制限する。
- チェストはすべて中身を持つようにする。
- 中身候補:
  - ゴールドキャッシュ
  - 回復アイテム
  - 弾薬
  - 低〜中レアリティの武器
  - 低確率でアタッチメント
- 序盤チェストでは強すぎる武器を出さない。
- 生成場所は補給/キャッシュ系の部屋アーキタイプを優先する。
- チェストが空になる場合は生成しない。

## 4. ポップアップ表示の小型化
- 一度に複数出た場合に画面を占有しないようにする。
- 表示サイズを小さくする。
- 最大表示数を制限する。
  - 推奨: 最大3件
- 4件目以降は古いものを消す、または短縮表示にする。
- 本文は2行程度までに制限する。
- NPCメニューが開いている時は、不要なポップアップを出しすぎない。

## 5. クエスト報酬レア武器のランダム化と序盤制限
- レア武器報酬はプレイごとにランダム選択にする。
- ただし章/階層に応じて候補を制限する。
- 序盤の制限案:
  - Chapter 1〜4: pistol / smg / shotgun の低価格帯中心
  - Chapter 5〜9: rifle / smg / shotgun を解禁、sniperは低確率
  - Chapter 10〜14: rifle / sniper / lmg を段階的に解禁
  - Chapter 15以降: explosive を含む強武器候補を解禁
- 価格が高すぎる武器は序盤候補から除外する。
- レアリティ自体は「Rare以上」などの最低保証に留め、Legendary確定にはしない。

## 6. クエスト達成条件の改修
- 現在のクエストは単純な累計条件が多いため、章/階層/戦闘スタイルに応じて少しやりごたえのある条件を追加する。
- 既存の基本タイプは残す。
  - Kill
  - Floor Clear
  - Headshot
  - Stealth Kill
  - Boss Kill
  - Gold Earn
  - Survive
  - No Damage
  - Speedrun
  - Weapon Mastery
- 追加または派生させたい条件:
  - `ELITE_HUNT`: 強化/特殊個体を一定数倒す。
  - `CLOSE_RANGE`: 近距離で敵を倒す。
  - `LONG_RANGE`: 遠距離で敵を倒す。
  - `LOW_HEALTH_CLEAR`: HPが一定以下の状態でフロアをクリアする。
  - `NO_MEDIC_CLEAR`: 回復NPCや回復アイテムに頼らずフロアをクリアする。
  - `CHEST_RECOVERY`: ダンジョン内チェストを発見して回収する。
  - `RARITY_KILL`: 指定レアリティ以上の武器で敵を倒す。
  - `TACTICAL_USE`: 投擲/特殊アイテムを使って敵を倒す、または妨害する。
  - `FAST_CHAIN`: 短時間内に連続キルする。
  - `EXTRACTION_STREAK`: 複数フロア連続で生還する。
- 章ごとの難易度方針:
  - Chapter 1〜4: 基本条件 + 軽い派生条件。プレイヤーに仕組みを覚えさせる。
  - Chapter 5〜9: ボス、距離条件、チェスト回収などを混ぜる。
  - Chapter 10〜14: 武器レアリティ、連続キル、低HPクリアなどを追加する。
  - Chapter 15以降: 複合条件やリスク付き条件を増やす。
- クエスト説明は、条件が分かる日本語/英語テキストを必ず追加する。
- UIでは、特殊条件のクエストに短いタグを表示する。
  - `ELITE`
  - `RANGE`
  - `RISK`
  - `LOOT`
  - `CHAIN`
- 実装は既存の `QuestType` を拡張する形を優先する。
- 既存セーブデータへの影響を抑える。
  - 既存クエストIDは可能な限り維持。
  - 新条件は新しいクエスト生成分から使う。
  - 既に進行中のクエストが壊れないよう、進捗Mapの形式は基本維持。
- すぐに全条件を完全実装しない場合の優先度:
  1. `ELITE_HUNT`
  2. `CHEST_RECOVERY`
  3. `RARITY_KILL`
  4. `FAST_CHAIN`
  5. `LOW_HEALTH_CLEAR`

## 7. レアリティ武器性能の実反映確認
- ダメージ補正:
  - 既存の戦闘処理で `RogueDamageMult` が参照されているか確認。
  - 参照されていなければ修正する。
- リロード短縮:
  - TacZのリロード時間に介入可能なイベント/API/ミックスインを調査。
  - 可能なら `RogueReloadMult` を実際のリロード時間へ反映する。
  - 直接反映が難しい場合、実装不能理由と代替案を記録する。
- マガジンサイズ:
  - `RogueMagMult` が初期弾数や最大弾数に反映されているか確認。
  - TacZ側の最大マガジン判定に反映されていない場合、可能な介入点を探す。
  - 表示だけ増えて実際には撃てない状態にならないようにする。

## 8. パーク選択画面の修飾子説明改行
- パーク選択画面の修飾子説明を読みやすく改行する。
- 表示方針:
  - 修飾子名
  - 効果倍率
  - リスク/条件
- 長文はカード幅で折り返す。
- カード下部のクリック表示と重ならないようにする。

## 実装順
1. NPCメニュー画面とメニュー用パケットを追加。
2. NPCインタラクトを「即メニュー表示」から「NPCメニュー表示」に変更。
3. Shop / Quest タブを通常インベントリ上部から隠す。
4. ポップアップ表示を小型化。
5. パーク選択画面の修飾子説明を改行調整。
6. チェスト生成数制限とルート投入を実装。
7. チェスト回収クエストの進捗イベントを追加。
8. クエスト達成条件を拡張し、章ごとの生成ロジックに混ぜる。
9. クエスト報酬レア武器のランダム化と序盤制限を実装。
10. レアリティ武器のダメージ/リロード/マガジン反映を調査・修正。
11. `compileJava`。
12. `build`。
13. mrpack再生成。

## 検証項目
- Commanderに話しかけるとNPCメニューが開き、選択後にクエストタブが開く。
- Quartermasterに話しかけるとNPCメニューが開き、選択後にショップが開く。
- インベントリ上部からShop/Questを直接開けない。
- NPC会話ポップアップと画面メニューが同時に過剰表示されない。
- チェストが1〜2個程度になり、中身が入る。
- チェスト回収クエストが進行する。
- 新しいクエスト条件がクエストタブで読める。
- 新しいクエスト条件の進捗が想定イベントで進む。
- 序盤のクエスト報酬で強すぎる武器が出にくい。
- レアリティ武器のダメージ、リロード、マガジン補正が実挙動として確認できる。
- パーク選択画面の修飾子説明がカード内で読みやすく折り返される。
