# Floor 5+ Balance Simulation Report

## Scope
- NORMAL難易度基準。
- 5層以降、100層までの通常敵成長を確認。
- プレイヤーは初期1パーク + 各フロアクリアごとに1パーク取得する想定。
- TacZ実銃DPSは実行時API依存でローカルJSONが無いため、武器はカテゴリ解禁 + レアリティ倍率の相対火力として扱った。

## Model Notes
- 敵HP倍率:
  - `(1 + 0.10f + 0.0005f^2) * expectedPrefixHp`
- 敵攻撃倍率:
  - `(1 + 0.05f + 0.0005f^2) * expectedPrefixDmg`
- 特殊個体率:
  - `min(0.95, 0.10 + (floor - 1) * 0.01)`
- 武器相対値:
  - カテゴリ解禁帯とレアリティ期待値を合成。
  - 実銃DPS、命中率、弾薬切れは未反映。

## Findings
- 5-15層:
  - 通常敵はおおむね妥当。
  - 5層時点の通常敵HPは約1.44xなので、通常戦闘は重すぎない。
  - ただし現在の5層ボスHP倍率は `6.28x` で、基礎HP120なら約754HP。通常敵との段差が大きい。
- 20-30層:
  - パークと武器解禁が敵HPを上回り始める。
  - 混合ビルドでも30層でTTK indexが約0.47まで下がる。
- 40層以降:
  - 現行パークは積み上がりが強く、敵HP成長よりプレイヤー火力成長がかなり速い。
  - 50層で通常敵HPは7.85xだが、混合ビルドの攻撃倍率は武器込みで約39x相当になる。
- 75-100層:
  - 特殊個体率はほぼ上限に近づくが、パーク累積のほうが強い。
  - 100層時点では混合でもTTK indexが0.07まで落ち、通常敵はかなり溶けやすい想定。

## Balance Risks
- 5層ボスだけが突出して硬い。
  - 通常敵成長に対して、初回ボスHP倍率が早すぎる。
- 中盤以降は逆にプレイヤー火力が伸びすぎる。
  - `DAMAGE`, `GUN_PROFICIENCY`, `FORTUNE`, `HEAD_HUNTER`, `RELOAD_SPEED`, 武器レアリティが乗算気味に重なる。
- 100層+想定なら、敵HP式よりパーク累積側に何らかの圧縮か敵側のAct補正が必要。

## Recommended Direction
- まず5層ボスHPを下げる。
  - 目標は450-520HP程度。
  - 5層のボス体験を軽くし、10層以降で徐々に重くする。
- 30層以降の敵にAct補正を追加する。
  - HPだけを大きく上げるより、特殊個体能力やアーマー/移動/射撃圧を増やす方がよい。
- パーク火力の終盤圧縮を検討する。
  - `DAMAGE` と `GUN_PROFICIENCY` は単純加算のままでもよいが、最終倍率側にソフトキャップを入れる候補。
  - `RELOAD_SPEED` はすでに下限があるので、ダメージ系より優先度は低い。
- 50層以降は通常敵よりも、エリート/ボス/特殊目標で難度を作るのがよい。
