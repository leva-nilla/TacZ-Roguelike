# P0-P2 Stability / Balance Fix Prompt

## Summary
- 直近レビューで P0-P2 と判定された問題を、既存システムの挙動を大きく変えずに修正する。
- 優先順位は「進行/報酬の悪用防止」「フロアクリア/ボス/パークの状態不整合防止」「序盤バランス破壊の防止」「導線と表示の最低限整理」とする。

## Scope
- P0/P1 は原則修正する。
- P2 は安全に直せる範囲を修正し、設計変更が大きいものは既存挙動に近い軽量調整で対応する。
- TacZ本体jarは直接改変しない。
- 通常ワールド利用は想定しないが、通常ワールドに副作用が出るイベント処理は抑制する。

## Key Fixes

### Currency / Quest Economy
- `CurrencyManager.addGold` を「実収入としてクエスト進捗を進める加算」と「返金/補填のように進捗を進めない加算」に分ける。
- ショップ返金、購入失敗返金、デバッグ加算は `GOLD_EARN` を進めない。
- クエスト報酬は実収入扱いにするが、`GOLD_EARN` クエストの自己増殖が強すぎる場合は進捗対象外にする。

### Boss Reward
- ボス初回報酬はボスUUIDではなく、プレイヤーのフロア単位で永続管理する。
- 同じボス階を再生成/再入場しても、同一プレイヤー・同一フロアの初回報酬は1回だけ。
- ボス武器報酬の価格/階層フィルタが空の場合に、無制限の全武器へフォールバックしない。

### Floor Clear
- フロアクリア処理は `floorCleared` が `false` の時だけ実行する。
- 抽出NPC生成、通知、クエスト進捗、速度/無傷/低HP判定が10tickごとに再発火しないようにする。
- クリア判定は可能な範囲で `tac_rogue_spawned` / 現フロアタグを使い、残骸やNPCで詰まりにくくする。

### Perk Apply / Reward Route
- フロアクリア画面と通常パーク画面で、パーク付与制限を共有する。
- `CURSED` / `OVERCLOCKED` / `TITANIC` / `CORRUPTED` などの上限を片方の経路だけで迂回できないようにする。
- ボスフロアクリア時は `PerkGenerator` のボス報酬ロジックを使う。
- フロアクリア画面のリロールはフロアクリア文脈を維持する。

### Map / Chest / Boss Floor
- ボスフロアのプレイヤースポーン部屋には通常Mobを湧かせない。
- ボスフロアの雑魚数を固定24体から抑え、ボス戦後の掃討作業化を軽減する。
- 通常フロアの敵数カーブを序盤から中盤にかけて緩くする。
- チェスト武器はショップ解放階層と同等のフィルタを使い、序盤に高Tier武器が出ないようにする。
- チェスト生成/中身は探索報酬として機能し、空チェスト/過剰チェストを増やさない。

### Rewards / Weapon Progression
- クエスト・ボス・チェストの武器候補は同じ階層進行ルールを参照する。
- 価格キャップが空の場合は、低カテゴリの安全な候補へ段階的に戻す。
- ショップ/ドロップ/チェストの解放タイミング差が大きすぎる場合は、極端な早出し/遅出しを緩和する。

### Combat / Balance
- ADS/伏せ/スニークの利得が重なりすぎないよう、ダメージ/検知/スタミナ軽減の値を調整する。
- 防御系パークの上限や表示を、実効値が読めるようにする。
- 回復/アーマーの即時性は残しつつ、連打で戦闘テンポを潰しすぎないようにする。

### Lobby / UX / Debug
- NPC経由のショップ/クエスト導線は維持しつつ、インベントリ側に残る古いタブ導線を誤解しにくくする。
- チュートリアル/クエスト詳細/ステータス表示に、現在やることが分かる最低限の文言を追加する。
- デバッグ権限は固定ユーザー名だけに依存せず、OP権限でも利用可能にする。
