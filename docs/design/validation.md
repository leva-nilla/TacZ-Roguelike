# ゲームデザインの差分と検証計画

[合意した意図](../design-intent.md)と `0.9.7` 修正ブランチ `b9d4b2b` を比較した記録。コードを読んで分かる挙動と、プレイしないと分からない手触りを分ける。**ここにある手順は未実施。** 実機は [開発・検証手順](../development.md) の使い捨て環境で確認する。

## 実装との差分・優先順位

| 優先 | 項目 | 先に確かめること・実装へ進む条件 |
| --- | --- | --- |
| 1 | **装備保全: プレステージ／Ironman** | 両方のリセットが装備選択フラグを外し、その後の初期配布で手持ちが消える経路。手持ち・スタッシュ満杯・次回装備選択・再ログインまで通し、取得済み装備や先に受け取った報酬が消えないことを最優先で確認。保全方法とリセット確認画面に載せる対象を決める |
| 2 | **途中撤退と連戦補給** | 撤退をいつ・どこで選べるか、戦闘中の即時離脱を許すかを決める。撤退で取得済みの成果は残り、達成報酬・連戦・補給箱の回数は復活しない。連戦は「3階＋次階到着」を基準に、ボスの計上、支給量・間隔、満杯時を決める |
| 2 | **Co-op の参加資格・離脱・再接続** | 任務種別ごとの「節目」を決める。排除・討伐は端末や防衛の開始とは違う。階層解放・通常戦利品・初回武器・初回パーク・連戦について対象を分け、参加前に何を獲得できるか見せる。再接続の猶予・復帰位置・任務が完了した場合・公開階への新規参加との違いを決める |
| 2 | **Co-op の味方ダメージ** | 同一公開階で銃・爆発・近接・ユーティリティごとに味方への実ダメージを確認する。味方ダメージなしを標準とし、仲間の行動で任務が破綻しない条件を決める |
| 3 | **照準疲労の専用演出** | 現行の実ダメージとHP下限は保つ。スタミナ切れ直後／猶予中／ダメージ発生／照準解除を見分けられること。実ダメージの原因を敵の攻撃と誤認しない表示を決め、音や色だけに依存しない |
| 3 | **100階の達成と深層の入口** | 100階への到達／ボス撃破／101階への進入を区別。初回ボス撃破を達成として表示し、深層メニューの表示と機能の解禁を分けるか決める |

「章構成」「常設の補給」「任意クエスト」など大筋が現行と合っていても、値や体感まで承認済みとは扱わない。致命的な装備喪失と、好みや手触りに関わる調整は別の変更にする。

## プレイテストの確認表

| 試す場面 | 観察するもの | 合格の目安 |
| --- | --- | --- |
| **初回セットアップ～1階** | 新規と経験者が、言語・キー・視点・初期装備・補給・出撃・回収を、ヒントあり／スキップで一周 | 新規が操作に詰まらず、経験者は進行を塞がれない。必要ならガイドを再読できる |
| **1～5階を別装備・別難易度で** | 任務の理解、1階あたりの時間、被弾・残弾・回復残量、ボスの予兆への反応 | 章の緩急があり、ボスは体力だけでなく立ち回りが違う。Easy と Normal が成立し、Hard 以上のペナルティが事前に伝わる |
| **同じ階を再生成／異なるテーマへ** | 部屋接続、スポーン直後の安全、任務マーカー、敵経路、照明・遮蔽、ボスへの到達 | 再生成で行動や経路が変わるが、理不尽な開始・行き止まり・達成不能はない。任務によって全滅以外の選択が成立 |
| **銃撃・隠密・近接・医療** | 開幕の発見、陽動の効果、弾の消費、被弾後の回復、スタミナ0での照準、両視点の操作 | 正面突破が成立し、隠密・近接も使いどころがある。自然回復だけで常時満タンにはならない。疲労のダメージを読み取れる |
| **負けた直後・資金が少ない状態から** | 帰還前後の装備・ゴールド・パーク、過去階での回収と買い戻し、低資金で使える対応弾・基本回復 | Normal で失うのは定めたゴールドと未達成の攻略。過去階が立て直しになるが、同じ箱や初回パークを繰り返し稼げない |
| **早めの帰還／3階連戦／途中撤退** | 新規階の順番と所持品、支給のタイミング、満杯や切断での扱い、旧階再訪による計上 | 帰還は損なだけの選択にならない。連戦は次の戦闘を助ける。早期撤退は取得済みの成果を保ち、クリア報酬を得ない |
| **装備・在庫・パークの中盤比較** | 初期武器の強化有無、銃種と弾コスト、付属品とレア度、複数のパーク特化、携行3種＋バッグ満杯時のUI | 1つの銃・パック・パーク系統だけが正解にならない。持ち込み・保管・購入の結果が理解でき、荷物管理だけが律速にならない |
| **公開Co-op の2クライアント** | 開始参加／任務節目前後の合流、ボス参加制限、支援役の報酬、通常補給箱、味方ダメージ、帰還・切断・復帰 | 目的は共同、取得品・連戦は個別。遅い合流で主要報酬だけ取れず、同じ攻略への復帰では適切に引き継ぐ。残った人の任務が続く |
| **クエストを無視する／任意挑戦を選ぶ** | クエスト章とフロア解放が混同されないか。低HP・無傷・速攻の表示、報酬と難易度 | 任意目標なしで通常進行でき、挑む人には違う攻略や報酬がある。必須装備を縛らない |
| **99階～深層と任意リセット** | 100階の到達／撃破、101階での専用育成、保持する資産の説明、プレステージ／Ironman 後の再装備と再ログイン | 100階ボス撃破が明確な区切り。深層とリセットは任意で、保持と告知された装備が容量や再選択で消えない |
| **HUD・通知・アクセシビリティ** | 戦闘中のHP・弾・疲労・目標、ボス警告、音なし・縮小UI・一人称／三人称、日英表示 | 重要情報は操作や色・音の一種類に依存しない。任意の通知を減らしても攻略の情報は残る |

記録には、ビルド、階と任務、難易度、人数、主要な装備・パーク、クリア時間と残弾・残HP、分かりにくかった箇所を残す。結果がなければ敵倍率・価格・支給個数・再接続秒数は確定値にしない。
