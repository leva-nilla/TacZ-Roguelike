# ゲームデザインの意図

2026-11-21 確認。**装備やパークを育てながら、少しずつ深く潜るゲーム。** 帰還は育成と補給のための選択で、失敗しても立て直して再挑戦できるようにする。[現行仕様](current-spec.md) と、このページの未実装の意図は区別する。

## 合意した判断

| 場面 | プレイヤーにしてほしい判断 | 仕様・状態 |
| --- | --- | --- |
| Normal で失敗 | リスクは感じるが、失敗1回で育成のやり直しにはならない | 現行維持。攻略をやり直し、ゴールドは5%減る。銃・パークは没収しない。Hard 以上のペナルティは今回決め直さない |
| フロアクリア後 | 補給に戻るか、今の装備で先に進むかを選ぶ | 両方の選択肢を残す。連戦には報酬を足す方針。**報酬は未実装** |
| クリア済み階への再訪 | 失敗後に資金や装備を立て直す | ゴールド・通常ドロップが目的。主要なパーク報酬と階層解放は先へ進む動機にする。通常補給箱は同じランで上限を復活させない |
| 同じ補給箱を仲間と発見 | 先着順を気にせず、自分に必要な品だけ持っていく | 通常補給箱はプレイヤー別・取り出し専用。同じ生成中は閉じても残り、再生成したら消える。任務用の箱は今回変更しない |

## 次に設計するもの: 連戦の補給ボーナス（未実装）

| 確認した論点 | 合意内容 | 狙い |
| --- | --- | --- |
| 達成条件 | 未クリア側の階を **2〜3階連続クリア**。具体的な階数は未決 | 短い先の目標を作り、低い階の周回を最適解にしない |
| 報酬 | 弾・回復などの**その場の補給**。限定パークや永続報酬は連戦ボーナスにしない | 連戦を続けやすくする一方、帰還を選んだ人の長期育成を損なわない |
| 公開Co-op | **プレイヤーごとのクリアと直行**で数える。仲間の参加・離脱では自分の連戦をリセットしない | 同じチームにいる時間ではなく、自分で先へ進んだ判断を評価する |

### 実装前に詰めること

| 未決 | 判断のために見ること | 初回の候補（未合意） |
| --- | --- | --- |
| 2階か3階か、ボスを含むか | 任務ごとの所要時間と、通常の残弾・回復残量 | まず3階を試し、初回に完走できるプレイヤーが少なすぎれば2階に下げる |
| いつ渡すか、何個渡すか | 次階へ行く理由になるか。バッグ満杯や取り漏れで損をしないか | 直行して次階に到着した時点で少量支給。即時に使える物を優先する |
| 何を初クリアとみなすか | 次階の解放・パーク取得・任務クリアは同じタイミングではない | 初クリアはサーバーが階層達成を確定したときに判定し、報酬の選択画面を閉じても二重計上しない |
| リセットと途中参加 | 失敗・ロビー帰還・切断・旧階再訪・公開階の途中合流で不公平や二重払いがないか | 失敗・意図的な帰還・旧階再訪では区切る。切断／再接続と、任務終盤だけ合流した場合の扱いは別に決める |
| 表示と失敗時の納得感 | 残り何階で何を得るか、帰還したら何を失うかが伝わるか | クリア画面で進捗と報酬を先に見せる。通常報酬は帰還しても失わないと区別する |

初回の確認では「ロビーに戻らず進む理由はあるが、戻った人の育成は遅れすぎない」「旧階の再訪で連戦ボーナスを稼げない」「協力相手の離脱で自分の達成が消えない」の3点を判定する。詳細を決めるまではバランスや報酬コードを変えない。
